Le tableau d'adressage IPv4, case après case.

Ce manuel vous accompagne pour remplir la fiche d’adressage IPv4 et le tableau de sous-réseaux FLSM. Ouvrez le chapitre souhaité, puis le soufflet correspondant à votre travail. Dans les cases binaires, on écrit uniquement les 1 : les zéros restent vides.

1. Fiche d’adressage IPv4

Je complète le tableau binaire, puis le tableau décimal, avant de calculer le nombre d’hôtes utilisables.

1.1 Tableau en binaire
ÉTAPE 01 / 05

Je place l'adresse d'hôte et le CIDR

Dans chaque octet, les colonnes valent toujours 128 · 64 · 32 · 16 · 8 · 4 · 2 · 1.

A · Je transforme chaque octet en binaire

Exemple : 172 = 128 + 32 + 8 + 4. Je mets un 1 sous ces quatre valeurs. Je recommence pour 19, 86 et 173.

1721 0 1 0 1 1 0 0190 0 0 1 0 0 1 1860 1 0 1 0 1 1 01731 0 1 0 1 1 0 1

B · Je place le CIDR

Avec /27, je place 27 chiffres 1 depuis la gauche. Si je reçois le masque 255.255.255.224, je le convertis d'abord en /27 et le reporte dans le tableau décimal.

Je trace ensuite une barre après le 27e bit, à partir de la ligne CIDR, sans traverser la ligne d'adresse d'hôte.

Le tableau binaire

Sur smartphone : fais défiler le tableau horizontalement. La barre orange sépare réseau et hôtes.

ÉTAPE 02 / 05

Je construis les quatre adresses

À gauche de la barre : partie réseau

Je conserve un 1 uniquement lorsque l'adresse d'hôte ET le CIDR valent 1. Sinon, la case reste vide. Je recopie ensuite cette partie réseau sur les quatre lignes.

À droite de la barre : partie hôtes

Adresse du réseauTous les bits hôtes à 0.
1re IP adressableTous à 0, sauf le dernier à 1.
Dernière IP adressableTous à 1, sauf le dernier à 0.
BroadcastTous les bits hôtes à 1.
L'ASTUCE DE PÉPETTE

00 / 01 / 10 / 11

Regarde les deux derniers bits, dans l'ordre des quatre lignes : réseau 00, première 01, dernière 10, broadcast 11.

Dans la fiche papier, les 0 restent vides. Cette astuce concerne les réseaux ayant au moins deux bits hôtes.

1.3 Calcul du nombre d’hôtes

Calcul du nombre d’hôtes utilisables

Pour calculer le nombre d’hôtes utilisables, j’applique la formule 2(32 − CIDR) − 2.

/27 → 32 − 27 = 5 bits hôtes
25 − 2 = 30 hôtes

On retire les adresses réseau et broadcast. Les préfixes /31 et /32 sont des cas particuliers non étudiés ici.

2. Sous-réseaux FLSM

Je découpe le réseau en sous-réseaux de taille identique, puis je calcule le nombre d’hôtes disponibles dans chacun.

2.1 Tableau FLSM
ÉTAPE 05 / 05 · EXTENSION FICHE A3

Je découpe en sous-réseaux de taille fixe

En FLSM, tous les sous-réseaux possèdent le même nouveau préfixe et donc le même nombre d'adresses.

A · Je détermine les bits empruntés

Exemple : je découpe 192.168.10.0/24 en 4 sous-réseaux. Je cherche le plus petit nombre de bits n tel que 2n ≥ 4. Ici n = 2.

B · Je calcule le nouveau préfixe

/24 + 2 bits empruntés = /26

C · Je complète les réseaux et broadcasts

Les deux bits empruntés prennent successivement les valeurs 00, 01, 10, 11. Les six derniers bits sont à 0 pour le réseau, à 1 pour le broadcast. Je convertis ensuite en décimal.

Découpage binaire → décimal

La numérotation commence à 0 : sous-réseaux 0, 1, 2 et 3.

N°Bits empruntésRéseau (dernier octet binaire)Broadcast (dernier octet binaire)Réseau décimalBroadcast décimal

Pour compléter ma fiche A3

Je note d'abord les bits empruntés, le nouveau préfixe et le nombre d'hôtes. Puis, pour chaque numéro de sous-réseau, je remplis les cases binaires du réseau et du broadcast avant de convertir les deux adresses en décimal.

2.2 Calcul du nombre d’hôtes

Nombre d’hôtes utilisables par sous-réseau

Le nouveau préfixe est /26.

32 − 26 = 6 bits hôtes
26 − 2 = 62 hôtes par sous-réseau
